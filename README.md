# AA 分账计算器 (aa-splitter)

聚会、旅行、合租之后，谁给谁转多少钱，一键算清，转账笔数最少。

在线演示：待部署，部署后填写真实链接。

## 这是什么

多人多笔消费的 AA 分账工具。先把每一笔消费记下来：谁付的钱、多少钱、哪些人分摊。记完一键算账，得到一份转账清单，写明谁转给谁、转多少，笔数已经压到最少。还能生成一张账单图，直接分享到微信群。

适合饭局、旅行、合租、团建这些需要 AA 的场合。

## 怎么用

1. 加成员：输入每个人的名字。
2. 记消费：选谁付的钱、填金额、勾分摊人、写一句备注。
3. 算账：看转账方案，复制文字或生成账单图分享。

第一次用可以点「填入示例数据」，看一遍完整流程再清空重记。

## 最少转账是怎么算的

这是本产品的确定性计算层，全部由代码算出，全程不使用任何大模型：

- 金额按整数分计算。所有金额先换算成整数分再运算，不用浮点数，所以不会丢一分钱，也不会多一分钱。
- 每笔消费在分摊人之间平分。除不尽时，余下的几分钱按勾选顺序分给排在前面的分摊人，规则固定，每次结果都一样。
- 每个人最后只有一个净余额：正数表示大家欠他，负数表示他欠大家。
- 净余额不为零的人数不超过 15 人时，用子集动态规划找出零和分组的最优划分，转账笔数是可证明的最少笔数。
- 超过 15 人时，改用最大欠款人对最大收款人的贪心配对。结果仍然正确，每个人最后都结清，笔数不超过人数减一，只是不再保证最少。
- 测试用 300 组随机账单对照独立的暴力搜索实现验证：每组都结清、金额守恒、笔数等于暴力搜索得到的最少笔数。

## 账单图

点「生成账单图」，用 Canvas 在本机画一张账单图片：消费明细、转账方案、合计金额都在图上。图片只存在本机浏览器里，点保存可以下载，长按也可以保存。

## 数据与隐私

- 数据只保存在本机浏览器的 localStorage，不上传服务器，不需要注册登录。
- 没有后端，没有账号，没有第三方统计。清掉浏览器数据就等于清掉账单。

## 合规与边界

- 本产品不涉及股票、加密资产、资金托管，不碰任何人的钱，只算用户自己录入的消费。
- 金额与分摊关系全部由用户录入，工具只做算术，不提供任何理财或投资建议。
- 转账本身请在微信、支付宝或银行里完成，本产品不发起、不代理任何转账。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址即可使用。

## 测试

```bash
npm test
```

测试覆盖：分账规则（余数分配、付款人不在分摊人之内、两笔消费抵消）、最少转账笔数（经典反例、随机 300 组对照暴力搜索、15 人边界、18 人贪心回退）、账单图排版（行高随内容增长）。

## 技术栈

React + Vite + Tailwind CSS + TypeScript，纯前端，零后端，零服务器成本。
